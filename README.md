# CableBot ⚡

Telegram Bot for Electrical Cable Sizing Calculations

## معرفی

CableBot یک ربات مهندسی برای محاسبه سطح مقطع کابل‌های برق است.

قابلیت‌ها:

- محاسبه جریان بار
- انتخاب کابل بر اساس ظرفیت جریان
- بررسی افت ولتاژ
- افزایش سطح مقطع در صورت نیاز
- پشتیبانی از کابل‌های موازی
- تولید گزارش PDF فارسی


## محاسبات انجام شده

- جریان تک فاز
- جریان سه فاز
- ضریب توان
- افت ولتاژ
- ضرایب تصحیح دما
- ضرایب گروهی کابل
